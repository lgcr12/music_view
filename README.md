# Lyric Veil

一个简约、高级的全屏歌词覆盖幕布。

## 运行

```bash
npm install
npm start
```

打开：

```text
http://localhost:5173
```

## 使用

- 粘贴 LRC 格式歌词。
- 填写歌曲和艺人。
- 或点击“自动找 LRC”，按当前歌名和艺人从 LRCLIB 搜索并导入同步歌词。
- 也可以直接选择本地 `.lrc` 文件导入。
- 点击播放和全屏。
- 点击右上角收起设置面板，让歌词覆盖整个屏幕。

## QQ 音乐同步

点击“读取 QQ 音乐”会调用本机 `osascript`，尝试读取 QQ 音乐窗口标题。

点击“跟随播放”会优先使用 macOS 系统级 Now Playing 信息同步：

- 当前歌曲 / 艺人
- 当前播放进度
- 歌曲总时长
- 播放 / 暂停状态

导入或粘贴带时间戳的 LRC 后，歌词会按 QQ 音乐当前进度实时滚动。你在 QQ 音乐里暂停、继续、切歌或拖动进度，页面会在下一次轮询时跟上。

开启“跟随播放”后，如果检测到切歌，页面会自动用当前歌曲、艺人和时长去 LRCLIB 搜索同步歌词，并在找到后导入。

限制：

- 不破解 QQ 音乐，不读取账号、音频流或 App 内部歌词；歌词来自公开 LRCLIB 接口。
- 如果系统级 Now Playing 不可用，会退回读取 QQ 音乐可访问文本。
- macOS 可能需要在“系统设置 → 隐私与安全性 → 自动化/辅助功能”里允许终端或 Node 控制系统事件。

## LRCGET

已经下载 macOS Apple Silicon 版本到：

```text
tools/LRCGET_1.0.2_aarch64.dmg
```

LRCGET 适合批量管理本地音乐文件的歌词；本项目的网页自动导入使用同源的 LRCLIB API，适合按 QQ 音乐当前播放歌曲即时匹配。
